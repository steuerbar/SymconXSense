# X-Sense Rauchmelder Kachel

Die Kachel zeigt alle Instanzen des Moduls `X Sense MQTT Device` automatisch in einer kompakten
Übersicht an.

Pro Rauchmelder werden Produktbild, Name, Gesamtzustand, Onlinezustand, Rauchalarm,
Gerätestörung, Batterie, Lebensdauer und der letzte Empfang dargestellt. Der Kopfbereich zeigt
den Gesamtzustand und die wichtigsten Zähler.

Für eine übersichtliche Darstellung wird eine Kachelgröße von mindestens 4 × 4 Feldern empfohlen.
Die Geräteliste ist innerhalb der Kachel scrollbar.
